# Fruit Slice GK — 12 Animal Build

Files:
- index.html — complete functional game
- manifest.json — PWA manifest
- sw.js — service worker with bumped cache version
- icon.svg — app icon source

Animals:
Lion, Tiger, Panda, Elephant, Bunny, Monkey, Fox, Koala, Frog, Puppy, Kitten, Unicorn.

Core interaction:
1. Choose an animal.
2. Start the game.
3. Tap an answer fruit.
4. The selected animal jumps toward the tapped fruit.
5. Its separate knife swings.
6. Correct fruit shows slice/splash feedback.
7. Animal lands and the next question loads.

The game generates 1000 kid-friendly question rounds from a curated fact bank and randomized templates.

For GitHub Pages, upload/replace index.html, manifest.json and sw.js in the repository root. Keep the same branch/root Pages configuration.
