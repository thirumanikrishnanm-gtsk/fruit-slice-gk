Fruit Slice GK — Phone-Ready PWA

Files:
- index.html — game
- manifest.json — installable PWA configuration
- sw.js — offline cache/service worker
- icon-192.png / icon-512.png — app icons

PHONE-ONLY NEXT STEP
1. Put this folder online using a static hosting service that gives you an HTTPS URL.
2. Open the URL on your Android phone in Chrome.
3. Use Chrome's "Install app" / "Add to Home screen" option to test it like an app.
4. For Google Play packaging, enter the HTTPS URL into PWABuilder and choose Android.

IMPORTANT
The PWA must be hosted on HTTPS before browser installation and PWABuilder packaging.
